## 空调和热水不能省略的确认

空调预算按7个可关门房间+客餐公共区共8区拆分：7×2599+6399+6000=30592元。七台1.5匹和一台3匹仅用于形成可审查的设备价锚点，不能视为已经按每间负荷选定。逐房负荷、客餐厅连通性、八个合法室外机位和冷凝排水必须确认后才下单。若外立面放不下，应比较小多联等方案，不占窗、不挤消防和检修通道。
