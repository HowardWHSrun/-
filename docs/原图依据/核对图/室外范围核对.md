## 必须留空或单列待核的区域

1. **南端下沉庭院上空。** 原生3C6686明确写出名称。内上口参考 x=0.14~9.46、y=-5.76~-4.02，约9.32×1.74m。y=-3.78~-4.02为护栏/边缘构造带，也不计连续庭院地面。`A-HOLE`斜折线8BBB6/8BBB7是洞口示意，不能拿来画一块斜边铺地；地下底板、标高和下沉庭院入口未在本轮核实。
2. **东侧下沉庭院上空。** 首层内上口 x=7.92~9.48、y=8.72~14.78，1.56×6.06m。首层与上层不能填板、填绿地。底部景观只能列为独立概念，需地下层通路、标高、防水排水依据。
3. **北入口。** 原台阶看线x=2.00~4.26，y=15.75/16.05/16.35，实体3EC7E5~3EC7ED。外围标高3C6697/3C6698为-0.400/-1.800（结），三角锚点[2.916,17.344]。存在地面标注不等于拥有闭合前庭范围；入口投影也不是同一标高的整块平板。
4. **二层东侧平屋面。** 84AAD写“平屋面”，旁有3.570（结）与2%坡度；参考范围[7.92,4.10,9.48,8.48]。本轮不将其当可达生活露台。
5. **北侧设备平台。** 二层84AA5与三层84B55明确设备用途。三层标签[0.940,14.174]，与曲线檐口相邻，未核定闭合花园使用面；JSON仅定位参考框，不作楼板/花园生成多边形。
6. **屋面。** 保留第6户三层原生 A-ROOF 中6组闭合投影参考；曲线在来源图中按0.1mm容差采样，完整屋脊/檐口三维高程尚未核完。不能用统一水平顶板宣称复原整座原屋顶，更不能把屋面投影当花园地面。
7. **北侧、东外墙外扩。** 在4,588条原生文字/属性中搜索红线、用地界、用地红线、地界、产权、总平面、围墙均无命中；本轮未发现可归属第6户的闭合总平面地界。这是现有证据不足，不是保证原DWG任何位置绝对没有地界。9.60m轴宽和9.72m外墙坐标都不能充作产权边界。
