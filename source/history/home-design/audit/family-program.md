# 四人家庭与未来小家庭：功能规划备忘

这是用于概念方案的家庭需求推演。原始文件包含连续多户及多个楼层，尚不能确认哪一户属于用户，不能将整排建筑计入一家，也不能确认朝向、单户可用面积、采光条件或结构改动条件。以下楼层安排是可检验的候选关系，并非已套合的施工平面。

## 1. 先固定六条家庭原则

1. 现在至少三间完整、可关门的卧室：父母、儿子、妹妹。妹妹的房间不能默认因哥哥结婚生子而让出。
2. 未来至少有一间可转儿童房，并与父母（儿子与未来妻子）同层。当前可作弹性客房，但不占用书法房。
3. 书法房、妈妈工作室、爸爸操盘房均有真实门、储物和独立工作位置；不以楼梯间、穿堂或卧室角落冒充专属房间。
4. 电梯与楼梯形成连续交通核心；没有电梯时仍有完整楼梯联系。优先保留合理交通、厨房、卫浴和收纳，再安排影院、健身、茶室等附加房间。
5. 有窗位置优先给卧室和每天长时间使用的三间工作室。地下室主要承担设备、家政、低频收纳和条件合适时的活动空间。
6. 父母55岁，当前舒适性与长期可转换性一起考虑；“适老”不等于把首层塞满卧室、三间工作室和厨房。

## 2. 建议主案 A：首层共享，二层父母和妹妹，三层年轻家庭

适合首层不足以同时容纳完整公区和父母套房的多层联排。属于当前可优先推演的方案，必须以实际户界和面积复核。

| 层 | 主功能 | 关键关系 |
|---|---|---|
| B1 地下室 | 既有停车（仅在原图/产权允许时）、设备、换季库、工具；剩余空间可作健身或影音 | 设备可维护、储物不侵占出入口；没有采光/通风/合规条件时不设置长期卧室或工作室 |
| B1M 地下夹层 | 家庭杂物、弹性阅读/活动、清洁储物 | 是否使用取决于真实净高、合法性、采光通风和疏散；不是默认新增一层 |
| 1F | 玄关、共享客餐厅、可关闭的中厨、餐边备餐、可淋浴公卫；妈妈干工作室邻接合法的植物区 | 玄关→厨房便于买菜；餐厨→餐桌短路线；工作室有完整门和窗，未来可改长辈卧室；花房是否可封闭另核实 |
| 2F | 父母套房、爸爸独立操盘房、妹妹完整套房/独立卧室配卫生间；楼层布草 | 爸爸房靠近父母区；妹妹通过公共楼厅进入自己的房间，不穿过父母区域；保护双方隔音 |
| 3F | 儿子未来夫妻主卧、预留儿童房、独立书法房、可共享的家庭卫浴、衣物及婴童收纳 | 夫妻与幼儿同层；儿童房当前作弹性客房；书法房独立且可上锁，不兼儿童通道 |
| 屋面 | 经核实允许后的晾晒/维护/轻量户外休憩 | 不默认可封闭、不预设玻璃花房、重型花池或泳池；电梯到顶层还是屋面由条件决定 |

优点：首层与庭院的日常联系保留，所有家庭成员专用房有明确位置，儿子未来成家后边界清楚。代价：父母现在睡二层，需要电梯与楼梯都好用。

长期转换：首层妈妈工作室预留床位、衣柜、电源与遮蔽条件，邻近公卫从一开始具备淋浴条件。父母未来需要完全在首层生活时，这间转成父母卧室；妈妈干工作室可移至原二层父母房的一部分。不要把“将来可能加淋浴”当作已经完成的适老安排，排水和防水应在改造设计时确认。

## 3. 备选 B：父母现在住一层

| 层 | 功能分配 |
|---|---|
| 1F | 完整父母套房、客餐厨、玄关；妈妈工作室/花房至少其一需转至真实采光条件更好的上层 |
| 2F | 妹妹独立套房、爸爸操盘房、妈妈干工作室及可达的植物区（如合法外部空间具备条件） |
| 3F | 儿子夫妻主卧、儿童预留房、书法房 |
| B1/B1M | 设备家政和低频活动，遵循原有合法空间条件 |

优点：父母可少依赖电梯；父母夜间卫生间、吃饭和出门路线最短。代价：首层公区容易局促，妈妈上下楼增加；如果单户首层小，不能以压缩厨房、移除淋浴或挤窄通道硬塞。

选择条件：先在首层摆出真实尺寸的父母床、双侧通行、衣柜、带淋浴卫生间、可工作的中厨、餐桌及电梯楼梯，再判断是否成立。无法同时成立就回到主案 A，不拿整个联排建筑的宽度补足面积。

## 4. 三个专属空间要真正好用

### 儿子的书法房

- 中央实木长案，桌面与主要窗面形成侧向采光关系，避免手部严重投影和纸面眩光；人工照明补足夜间使用，色温/照度在具体灯光设计时验证。
- 先用常用纸幅和装裱方式确定台面，再摆周边通行和储物，不能只按“有一张书桌”交差。
- 宣纸平抽、卷轴架、书柜分区，珍贵作品避直晒与受潮；日常墨水、刀具放在可锁的低风险储位。
- 独立洗笔点优先靠已有给排水立管；如条件不允许，在附近家政盆集中洗笔，不把新增排水管横穿卧室。墨汁和清洗残渣的排放方式由具体材料与排水要求决定。
- 作品展示墙与书写区分开；不要把花房湿空气引入书法纸张收藏区。

### 妈妈的阳光花房 + 毛线工作室

- 用“看得见、空气可隔开”的完整玻璃门和隔断相邻设置：干侧织物与人长期工作，湿侧浇水、换盆和植物。
- 干侧：工作台、舒适坐椅、封闭毛线柜、针具分格、作品展示；存放前确保织物干燥，柜体避开可结露的冷外墙和直晒位置，监测潮湿风险。
- 湿侧：易清洁防滑地面、合法排水/接水托盘、可取水位置、换盆工具柜；根据植物配置通风与遮阳，夏天重点避免玻璃空间过热。
- “阳光”不等于把所有房面做成玻璃；常坐的工作桌宜有遮阳、柔光与独立室内温湿度控制。
- 不把空调回风设成从花房穿过毛线工作室；玻璃房的封闭、外观、排水、荷载和物业规则需在选型前核实。

设计依据：RHS介绍温室需要通风与遮阳，且湿润地面或喷雾可主动提高湿度；加拿大保护研究所说明高湿度、温暖和缺乏空气流动会促进纺织品霉菌生长。因此本方案推导出“邻接而分隔”的做法；不是对具体室内湿度或通风量的施工规定。[RHS 温室通风与遮阳](https://www.rhs.org.uk/garden-features/ventilation-and-shading-greenhouses)；[CCI 纺织品霉菌](https://www.canada.ca/en/conservation-institute/services/conservation-preservation-publications/canadian-conservation-institute-notes/mould-growth-textiles.html)。

### 爸爸的独立操盘房

- 以一张可容纳三屏的真实桌面和调节座椅为中心，屏幕侧对窗，配可调遮光；不能让大玻璃窗正对屏幕或正对眼睛。
- 桌下线槽、足够电源及有线网络，网络设备与主机可散热；选定设备后由电气设计复核回路，重要设备可按负荷选 UPS。
- 安静关闭门，视频/语音通话不传进父母卧室；储物柜兼遮挡杂乱线缆，柜内设备不能密闭闷热。
- 屏幕内容为功能示意，不涉及具体证券或收益建议；房间服务长时间阅读、研究与休息。

## 5. 不应遗漏的配套与动线

- 厨房：入口附近可临时放菜，冰箱/储粮→清洗→备菜→灶具连续；水槽与灶具之间留真正可用的备菜台，排烟路线尽量短且按批准条件设置。中厨可关闭，餐边柜放小家电和茶水；不默认必须额外建一间西厨。
- 餐桌：按现在四人、未来六人日常共餐安排可扩展方案，先保留拉椅及经过的空间，再选岛台。岛台不是必需品。
- 洗衣：楼层衣物收集点→电梯→主洗衣房→晾晒/烘干→布草柜。主洗衣优先靠真实排水、通风和晾晒条件；避免把频繁上楼的洗衣动线全压到潮湿地下室。可设一组主洗烘，楼上预留条件按实际需求配置。
- 每层楼厅设置适量清洁/布草储位；扫地机回充、吸尘器、家政盆、垃圾分类有位置，不挤在电梯等候区。
- 湿区尽量上下叠合，既有立管附近布置厨房、卫生间、洗衣；不要为“平面好看”到处跨层横穿排水。
- 电梯服务实际存在且允许停靠的楼层，优先与楼梯同一交通核心；尺寸依据未来助行器/轮椅需求和厂商完整参数确定。不能凭概念图认定井道尺寸、底坑、顶层高度或承重满足。
- 入户到电梯、常用卧室到卫生间的路径尽量连贯平整；用照明和可抓握扶手支持夜间行动，具体净宽等由测绘与适用规范确认。
- 儿童预留房与夫妻房同层；楼梯/窗/电梯与插座等安全设施在深化时一并落实，洗涤用品、药物、针具、墨水可锁收纳。

## 6. 面积不足时的取舍顺序

先取消或合并第二客厅、独立茶室、影音、健身、大挑空、重复衣帽间和重复备餐厨房；然后缩小装饰展示与走廊。保留三间现有卧室、一间儿童预留房、三个专属工作房的实际使用条件，保留完整的厨卫、家政、收纳和交通。若保留项目仍放不下，应向用户展示明确的两案取舍，不能将两个互相冲突的功能虚画成同一空间里的两间房。

## 7. 主代理出图时的文字建议

图面应同时写明“全楼参考图 / 单户边界待确认”和“功能关系示意，未按实际尺寸套合”，并避免南北箭头、未经验证的面积总数和梁柱可拆标记。氛围图另写“室内氛围概念，非原图精确复原”。
